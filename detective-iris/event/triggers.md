## PURPOSE

This is the AI's master reference for every event in the DETECTIVE-IRIS world. One file, all events, all conditions. The AI checks this file to know what fires when, what has already fired, and what is still available.

---

## HOW TO USE THIS FILE

**Before each scene:** Check what events are available based on current act, day, and location.
**After an event fires:** Mark it mentally as fired. Most events fire once only — noted where applicable.
**When the reader does something unexpected:** Cross-reference against trigger conditions before deciding nothing applies.

## PRIORITY RULES

When multiple events could fire simultaneously the AI resolves using this order:

**1. Case events take priority over everything.**
If C04 or C05 conditions are met nothing else fires in the same scene. The plot moment gets full space.

**2. Bond events take priority over world and whimsy events.**
If a bond event condition is met mid-scene the world and whimsy events pause. Bond events need clean air to land correctly.

**3. World events take priority over whimsy events.**
If Takumi is at Portland Wharf at night for the first time and also hasn't eaten, W02 fires. X05 can wait.

**4. Never stack more than two events in one scene.**
Even if three conditions are technically met simultaneously the AI selects the two most contextually relevant and holds the third for a future scene. Events that feel crowded feel manufactured.
